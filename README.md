# 全球转折信号监控

根据“破线、拐头、交叉、排列、乖离”五个步骤监控全球主要指数及证券当前所处的趋势阶段。

## 功能

- 实时报价与 30 秒自动刷新
- EMA20、EMA60、EMA120 趋势阶段判断
- 多头/空头五步骤状态展示
- 120 日乖离率与 MACD% 趋势强度
- 自定义全球指数与证券监控列表
- 默认覆盖北证50、沪深主要指数、恒生指数、日经225、标普500、纳斯达克、道琼斯、德国DAX和富时100
- 支持中文模糊搜索全球重要指数
- 桌面端与移动端响应式界面

## 本地运行

需要 Node.js 18 或更高版本，以及系统中的 `curl`。

```bash
npm start
```

打开 <http://localhost:5173>。

## 数据说明

- 实时报价与日 K：腾讯证券接口；日经225、德国DAX使用 Yahoo Finance；东方财富作为 A 股备用
- 市场热度仅为行情源返回的排序样本，不等同于完整全市场宽度

本项目仅用于行情研究和信号观察，不构成投资建议。
