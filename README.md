# 全球转折信号监控

根据“破线、拐头、交叉、排列、乖离”五个步骤监控全球主要指数及证券当前所处的趋势阶段。

## 2.0 交易系统

- 严格五步骤确认链，不允许跳级
- 映射“转折、开始、发展、极端、再转折”大阶段
- 价量时空：60日位置、量能比、阶段持续时间、120日乖离
- EMA20斜率与斜率加速度
- EMA20/60/120均线密集度
- MA20抵扣价
- 顶部与底部2B结构
- 人性之极与引力回归观察
- 基于EMA20底线和60日空间的机械参考盈亏比

## 功能

- 实时报价与 30 秒自动刷新
- EMA20、EMA60、EMA120 趋势阶段判断
- 多头/空头五步骤状态展示
- 120 日乖离率与 MACD% 趋势强度
- 自定义全球指数与证券监控列表
- 默认覆盖北证50、沪深主要指数、恒生指数、日经225、韩国综合指数、标普500、纳斯达克、道琼斯、德国DAX和富时100
- 覆盖 CME 比特币连续期货、彭博大宗商品指数、黄金、原油、铜、白银、天然气及主要农产品连续期货
- 覆盖美元指数，用于观察美元与风险资产、大宗商品之间的相对方向
- 支持中文模糊搜索全球重要指数
- 桌面端与移动端响应式界面

## 本地运行

需要 Node.js 18 或更高版本，以及系统中的 `curl`。

```bash
npm start
```

打开 <http://localhost:5173>。

## 数据说明

- 实时报价与日 K：腾讯证券接口；韩国、日本、德国、比特币期货和大宗商品使用 Yahoo Finance；东方财富作为 A 股备用
- 市场热度仅为行情源返回的排序样本，不等同于完整全市场宽度

本项目仅用于行情研究和信号观察，不构成投资建议。
